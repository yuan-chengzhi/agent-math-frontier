# 独立评审：首版选题是否固化

日期：2026-08-14。

本轮让三条相互独立的 agent 线路分别研究：已有 proof-assistant 形式化的问题、未形式化但适合搜索的问题、以及专门反驳整个选题方法的红队审计。它们没有修改仓库；主审重新检查关键动态来源后才合并结论。

## 三方一致意见

三方都认为，当前 agent 的最强证据集中在“候选对象紧凑 + evaluator 确定 + 搜索反馈密集”的构造/优化任务。形式证明是重要轨道，但 Lean 文件不是质量徽章：它会放大 mathlib 成熟领域的选择偏差，也可能存在量词、密度、边界或原意翻译错误。

三方也都反对用总解决数或单一适合度分数。大规模 Erdős 扫描中，题意误读、陈旧状态和已有文献结果的审核成本超过证明生成；因此 raw 整库与 active queue 必须分层。

## 独立意见怎样改变了首版

| 初始倾向 | 独立挑战 | 最终决定 |
|---|---|---|
| 主要从 Erdős、OEIS 与 Formal Conjectures 选题 | 未形式化 scout 找到 cage、degree–diameter、SRG 等证书更小、反馈更密的动态记录格 | 加入三类精确图构造，并把 cage `(3,13)`、degree–diameter `(3,9)` 列为基础设施试点 |
| “短整数见证”看起来天然适合 | formal scout 指出 Erdős #647 已深搜到巨大范围仍无信号 | 不收入 17 题精选；保留在 raw 层 |
| R(5,5) 影响力高，可能成为主攻 | 三方都认为证书与算力规模极大 | 只列长期旗舰观察项，不计入短期成功率 |
| FrontierMath book graph 题面极适合 | 页面在 2026 年持续出现新有限实例与在审无限族 | 降为孵化；每次攻击前重新冻结未覆盖 n |
| Hadamard 668 在形式库仍显示开放 | scout 发现 8 月 12/13 日已有精确构造声明；Epoch 随后临时改为 solved | 标为 `provisionally_solved_pending_primary_publication`，禁止写 open |
| scout 建议 `SW(25,16), SW(27,16), SW(29,16)` | 主审发现一般 weighing matrix 与 symmetric 变体被混用，且 2026 新论文又改变状态 | 不采纳；进入隔离区等待专家和最新参数表核清 |
| 计划把九维向量加权求总分 | 红队指出会 Goodhart 到低价值、易验证任务 | 删除总分，只保留硬门槛、向量和轨道内 Pareto 比较 |

最后一行尤其重要：独立 agent 的输出也是 lead，不是权威。SW 变体误判被核查拦下，说明“让多个 agent 调研”只有与一手证据、冲突保留和主审复核结合才有价值。

## 当前判断

首版 17 题仍有组合/图论偏重，但已经不是单一 Lean 题库的抽样：6 题在 proof-assistant 轨道，8 题在 exact-verifier 轨道，3 题在精确自然语言/专家审核轨道。图构造占比偏高是当前能力证据导致的有意选择，不应固化为项目定义。

短期最有信息量的三项试点是：

- cage `n(3,13)` 上界改进：验证短、记录较老、局部反馈密；
- degree–diameter `(3,9)` 记录：基线清楚、checker 简单、可以测试程序搜索；
- stretched LR 反例：有限边界、代数组合价值更高，可检验图搜索以外的泛化。

强正则图 `(69,20,7,5)` 是第四项候选，但应先冻结一个有意义的对称子类，避免把子类无解误报为总体不存在。Erdős #23 适合测试“反例搜索 + 精确优化证书 + Lean closure”，但资源风险高于前三项。

## 下一轮必须回答的问题

1. 三个试点的独立 verifier 是否已经被边界测试和故意攻击过？
2. 是否有至少一名领域 reviewer 愿意确认结果的意义与新颖性？
3. 图构造是否挤压了数论、代数和自然语言证明的探索配额？
4. 当前失败是否来自 agent 能力、搜索表示，还是题目本身缺少反馈？
5. 最近两周有哪些状态翻转、在审工作或新的高质量专家题单？
6. 若成功，产物是完整解、记录改进、有限实例、子类结果，还是仅仅新 checker？

没有明确回答前，`shortlist` 不升级为 `active`。
